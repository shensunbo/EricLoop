# 朋友好感度功能规格

来源：`draft_spec.md` 与 2026-10-21 会话确认。

## 人物与交互

- 底部“ppl”入口位于“设置”左侧，进入管理列表；新增使用加号，排行使用排行榜图标，其他明确操作使用图标。图标提供无障碍描述及长按说明。
- 昵称必填，性别、简介和备注可选。头像为本地默认男孩/女孩，未设置性别使用通用人物图标。
- 每个人自动分配唯一颜色，保存及恢复后保持一致，不提供手动改色。管理列表、排行和详情的好感度卡片使用该颜色的浅色背景。
- 支持新增、按昵称搜索、详情、编辑和删除。删除前确认，连同关联事件永久删除。

## 好感度

- 初始值可设置及编辑，默认 0，允许负数，不设置业务上下限，整数计算。
- 分值输入兼容中文输入法的全角数字与正负号，保存为标准十进制整数字符串。
- 新增事件只能 +1 或 -1，事件说明必填，发生时间取当前时间，不支持补记。
- 已有事件可编辑说明和整数分值，保留发生时间，不记录编辑历史，不支持单条删除。
- 当前分数为初始值与全部事件分值之和；事件变更后列表、详情、排行同步更新。
- 时间线按发生时间倒序展示当前事件内容。

## 排行

- 独立排行页仅显示名次、头像、昵称、性别、简介和总分，点击跳转详情。
- 支持好感度、最近互动、创建时间升降序，默认好感度降序。
- 同分按最近互动降序，其后按创建时间和 ID 稳定排序；无互动者在互动排序中排最后。
- 名次为排序后的连续序号。

## 存储和备份

- 手机使用独立 Room 数据库 `friends.db`。
- 主仓库 `data/ericloop/ppl.json` 是朋友功能的 GitHub 备份文件，共用原连接和 Token。
- 两种业务拥有独立备份模型、同步状态及恢复预览；普通同步检查冲突，强制上传需确认。
- 下载先校验和预览；确认恢复时检查连接、云端 blob 和本地版本，保存本地安全副本后原子替换朋友数据。
- 原记录数据库及 `data/ericloop/backup.json` 不包含朋友数据。

## 验证约定

不新增或运行单元测试，使用 APK 编译、Android Lint 和指定 USB 真机功能检查。真实云端上传/恢复未执行时须在实施记录中注明。
