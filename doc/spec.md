# EricLoop 首版需求与实现约定

用于个人想法与计划记录。Kotlin / Compose / Material 3，Room 本地保存，GitHub 手动备份。仅在当前真机 10AE970D5P0017U（V2324HA、API 35）运行验证，不新增或运行单元测试。

## 记录与收纳

- 标题必填，正文可空，支持多个标签、创建时间与最近修改时间。计划支持一次性/长期类型、可选截止日期。
- 记录支持一个可选 Android 系统 Emoji 图标：选择常用图标或用系统键盘自定义，未设置/清除后使用默认图标。列表、详情和历史目录在标题前显示；图标随备份和编辑历史保存，旧数据缺少该字段时使用默认图标。
- 想法可转为计划，保留 ID、创建时间和历史。计划状态：未开始、进行中、暂停、完成、放弃。
- 想法详情独立显示一次性与长期计划两个转换入口，纵向全宽排列；长期计划转换后支持进展打卡。
- 完成后从默认列表移入固定“已完成”视图；调整为其他状态自动移回。
- 删除进入回收站，恢复后按状态收纳；首版无永久清除。
- 长期计划自由打卡，一天可多次，备注可选，支持补记、编辑与删除。发生时间和实际操作时间分别保存，不允许未来打卡。

## 标签与查询

- 预定义标签：工作、学习、生活、健康、个人项目。自定义标签支持新增、重命名；标签使用稳定 ID，名称非空且不可重复。
- 预定义标签分别显示固定 Emoji；自定义标签创建时可选 Emoji，之后可修改或清除。未设置时显示默认 🏷️。标签 Emoji 出现在标签目录、筛选项和记录关联标签中，随备份和标签历史保存；旧备份缺少该字段时继续可恢复。
- 独立标签目录显示标签及记录数量；点击标签跳转独立记录列表，支持返回目录，也提供全部记录、无标签入口。
- 标签计数与列表包含想法、未完成计划和已完成计划；已完成计划排在末尾，两组内按最近修改时间倒序。回收站不参与普通筛选或计数。
- 标签记录页支持无标签、多标签任选匹配；与类型、状态、关键词条件取交集。
- 想法使用同一标签库；概览与完成视图支持关键词、类型和标签筛选。

## 完整历史

- 明确保存后记录一次事件，不逐字记录。包括创建、编辑、转换、状态、标签关联、打卡、删除、恢复；不记录无变化保存。
- 事件包含操作时间、稳定序号及修改前后完整内容，标签名称保存当时快照。标签管理事件单独记录。
- 当前对象与事件原子保存；编辑删除不擦除旧历史。
- “变更”页只列出计划和想法的标题，包含已完成及回收站记录；点击标题进入该记录的独立 Graph，支持操作类型及日期范围筛选，点击节点显示前后内容。返回后回到标题目录，不提供全部记录混合 Graph。
- 单条 Graph 的节点按操作含义使用不同浅色卡片，时间和操作名称始终可见；节点不重复显示页面标题。打卡类节点直接预览笔记内容，补记时显示实际发生时间；编辑、状态等节点不展开具体内容，完整前后快照仍在点击后的弹窗中。
- Graph 使用应用事件，不读取 Git 提交，不提供旧版本恢复。

## GitHub

- 仓库 shensunbo/EricLoop、main 分支，备份 data/ericloop/backup.json。用户确认仓库公开、数据公开明文。
- 备份包含格式版本、数据集 ID、修订号、导出时间、全部记录、标签、打卡和事件；Token 与手机设置不进入备份。
- 手机设置页输入此仓库细粒度 Token，Contents 读写权限；AES-GCM 加密本地保存，密钥在 Android Keystore，禁止日志泄露。
- 手动同步按钮。正常上传比对上次备份内容，代码变化不构成数据冲突。未知或有变化的云端数据需恢复或强制上传。
- 强制上传确认后，仅以本地数据覆盖备份文件；在远端最新提交上追加提交，保留代码及全部提交历史，不使用 Git 强制更新。
- 非强制分支更新处理并发；最多重试三次。上传期间新修改仍待同步。未知结果重新读取确认，不重复提交。
- 恢复独立操作：严格校验必需字段、引用、历史完整性；预览时间与数量，确认覆盖；先存本地安全副本，再原子替换，失败保留当前数据，不合并数据集。

## 页面与风格

底部记录、标签、变更、设置。概览为任务卡片；详情轻量笔记，长期计划增加进展笔记；标签分类卡片；变更使用轨迹和节点。统一靛蓝强调色、圆角、字体和留白，跟随系统深浅主题，提供加载、空状态、失败反馈。

概览“正在推进”和计划卡片统一使用非常淡的浅绿，“灵感收集”和想法卡片统一使用非常淡的浅蓝；已完成入口和页面用 🎉，完成卡片及详情状态采用低饱和磨砂金色，卡片增加细边框，标题旁显示 🏅。Tab 选中态按记录、标签、变更、设置分别用靛蓝、青绿、紫色、灰蓝；所有配色提供深色模式对应值。

首页“正在推进”“灵感收集”计数卡可点击，分别进入进行中计划和想法的独立列表；列表支持搜索与标签筛选，返回首页。

长期计划的进展笔记卡片紧凑展示发生时间和笔记，编辑/删除收在右上角菜单；搜索与 Graph 日期筛选使用较紧凑的单行输入框。

已完成入口、记录卡片及详情状态卡采用静态磨砂金属背景：柔和金色渐变、低对比高光与细颗粒纹理，提供深浅主题，保持文字和点击区域清晰。

素材来自 Material Symbols（Apache 2.0）和 Material 3；不需用户采购 UI 套件。

## 边界

首版中文名称 EricLoop；无自定义文件夹、图片附件、提醒、习惯频率统计、电脑分析、历史版本恢复或永久清除。长期计划存在打卡后不能改为一次性，避免破坏打卡归属。

## 验收

编译通过并在指定设备验收：记录/转换/状态/完成收纳/回收站；标签和组合筛选；打卡和 Graph；进程重启与深浅主题；同步失败、冲突、强制上传与恢复。无真实 Token 时明确标记云端成功路径未实测，不声称验证完成。
