# 基本目标
1. 一个android app，用于记录和跟踪我的一些想法和计划

# 粗糙需求
1. 需要记录想法和计划的创建时间
2. 需要记录每次变更的时间
3. 需要区分想法和计划是一次性的还是长期任务
4. 需要可以显示单个想法或计划的详细历史时间线
5. 需要使用结构化的数据存储方式，方便后续的查询和分析，数据需要保存到云端，可以保存在当前仓库的某个位置并同步到github，需要探索手机端如何同步数据
6. 需要一定的可拓展性，方便后续增加功能
7. 语言使用 kotlin
8. UI资源和风格告诉我去哪里找以及需要我做什么，UI不能做的太原始和难看
9. 长期任务，我需要可以打卡，并且备注打卡的内容
